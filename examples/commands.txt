The lab's command lines, in the order
they were first run. $TOKEN is the
administrator's bearer token from
transcript t03; addresses are the
lab's own (loopback), as a reader's
would be their machine's.

Install (pip route; see t01 for the
sandbox's offline variation):

  python3 -m venv open-webui-venv
  open-webui-venv/bin/pip install torch \
    --index-url https://download.pytorch.org/whl/cpu
  open-webui-venv/bin/pip install open-webui
  open-webui-venv/bin/pip install llama-cpp-python

Generate the secret key, start the
server:

  openssl rand -hex 32
  DATA_DIR=$PWD/data \
  WEBUI_SECRET_KEY=<that key> \
  OLLAMA_BASE_URL=http://127.0.0.1:11435 \
    open-webui-venv/bin/open-webui serve --port 8080

Prove it is up:

  curl -s http://127.0.0.1:8080/health
  curl -s http://127.0.0.1:8080/api/config

First account, sign-in:

  curl -s -X POST \
    http://127.0.0.1:8080/api/v1/auths/signup \
    -H 'Content-Type: application/json' \
    -d '{"name":"...","email":"...",
         "password":"..."}'
  curl -s -X POST \
    http://127.0.0.1:8080/api/v1/auths/signin \
    -H 'Content-Type: application/json' \
    -d '{"email":"...","password":"..."}'

Connections:

  curl -s http://127.0.0.1:8080/ollama/config \
    -H "Authorization: Bearer $TOKEN"
  curl -s http://127.0.0.1:8080/openai/config \
    -H "Authorization: Bearer $TOKEN"
  curl -s -X POST \
    http://127.0.0.1:8080/openai/config/update \
    -H "Authorization: Bearer $TOKEN" \
    -H 'Content-Type: application/json' \
    -d '{"OPENAI_API_BASE_URLS":
         ["http://127.0.0.1:8001/v1"],
         "OPENAI_API_KEYS":["sk-lab-placeholder"]}'

The llama.cpp backend (chapter 7):

  python -m llama_cpp.server \
    --model smollm2-q4km.gguf \
    --host 127.0.0.1 --port 8001
  curl -s http://127.0.0.1:8001/v1/models

Models and chat:

  curl -s http://127.0.0.1:8080/api/models \
    -H "Authorization: Bearer $TOKEN"
  curl -s http://127.0.0.1:8080/api/chat/completions \
    -H "Authorization: Bearer $TOKEN" \
    -H 'Content-Type: application/json' \
    -d '{"model":"<model id>",
         "messages":[{"role":"user",
                       "content":"..."}],
         "stream":false}'

Users (chapter 10; admin token):

  curl -s http://127.0.0.1:8080/api/v1/users/ \
    -H "Authorization: Bearer $TOKEN"
  curl -s -X POST \
    "http://127.0.0.1:8080/api/v1/users/<id>/update" \
    -H "Authorization: Bearer $TOKEN" \
    -d '{"role":"user"}'

Presets and sharing (chapter 9):

  curl -s -X POST \
    http://127.0.0.1:8080/api/v1/models/create \
    -H "Authorization: Bearer $TOKEN" -d '{...}'
  curl -s -X POST \
    http://127.0.0.1:8080/api/v1/models/model/access/update \
    -H "Authorization: Bearer $TOKEN" \
    -d '{"id":"<preset or base model id>",
         "access_grants":[{"principal_type":"user",
           "principal_id":"<user id>",
           "permission":"read"}]}'
