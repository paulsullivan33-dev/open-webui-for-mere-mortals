One honest wart: on first start the
embedding model (chapter 2) failed to
download in this sandbox —

  ERROR | open_webui.routers.retrieval:get_ef
  Error loading SentenceTransformer: Invalid port: ':1]'

— the sandbox's proxy environment
breaking the Hugging Face client. The
lab fetched the model's files with
curl into the standard cache layout
and restarted with proxy variables
removed and HF_HUB_OFFLINE=1, after
which the log shows:

  INFO | sentence_transformers... Loading
  SentenceTransformer model from
  /home/hatch/.cache/huggingface/hub/
  models--sentence-transformers--all-MiniLM-L6-v2/
  snapshots/1110a243...

Normal installs on normal networks
simply download it on first start, as
chapter 3 describes.
